# 화면 선택자 찾기

선택자는 네이버에서 별도로 알려주는 값이 아니라, 페이지 HTML에서 날짜나 버튼을 식별하는 CSS 표현식입니다. 참고 상품은 실제 화면을 조사하여 기본 인식에 등록했습니다. 날짜·시간·예약 진행 선택자는 비워 두세요. 최종 확정 자동 클릭을 켤 때만 최종 선택자가 필수입니다.

## Chrome에서 찾는 순서
1. 확장 팝업이 아니라 실제 네이버 예약 페이지를 엽니다.
2. 개발자도구를 엽니다. Windows: F12 또는 Ctrl+Shift+I. Mac: Command+Option+I.
3. 개발자도구 왼쪽 위의 요소 선택 아이콘을 누릅니다. 단축키는 Windows Ctrl+Shift+C, Mac Command+Shift+C입니다.
4. 페이지에서 원하는 날짜, 시간 또는 버튼 위를 클릭하면 Elements(요소) 탭에 HTML이 표시됩니다. 요소 선택 모드가 켜진 상태의 클릭은 요소를 검사합니다. 모드를 끈 뒤 예약 버튼을 클릭하면 실제 예약을 진행할 수 있으므로 구분하세요.
5. 선택된 HTML이 span이나 SVG라면, 위쪽 부모 요소 중 button, a 또는 role="button"인 요소를 선택합니다.
6. 해당 HTML 줄을 우클릭 → Copy(복사) → Copy selector(선택자 복사)를 눌러 확장의 해당 입력칸에 붙여넣습니다.
7. Elements 탭에서 Ctrl+F / Command+F를 누르고 선택자를 붙여넣어 어떤 요소가 선택되는지 확인합니다. 직접 버튼을 클릭하지 않아도 검증할 수 있습니다.

복사된 선택자가 `nth-child(...)`처럼 위치에 의존하면 달력 월 변경, 시간 목록 변경으로 다른 버튼을 가리킬 수 있습니다. 가능하면 아래와 같은 안정적인 속성을 사용하세요. 예시는 문법을 설명하기 위한 것으로, 실제 페이지에 그 속성이 있어야 작동합니다.

## 네 가지 입력칸
| 입력칸 | 검사할 실제 화면 | 찾을 요소 | 설정 방법 |
| --- | --- | --- | --- |
| 날짜 버튼 선택자 | 예약 첫 화면의 달력 | 원하는 날짜의 클릭 가능한 버튼 | data-date 등이 있으면 `button[data-date="{date}"]`. 여러 날짜에서는 `{date}`나 `{day}` 템플릿이 필요합니다. 속성이 없으면 기본 달력 인식을 사용하세요. |
| 시간 버튼 선택자 | 날짜를 선택한 뒤 나타나는 시간 목록 | 원하는 시간의 클릭 가능한 버튼 | data-time 등이 있으면 `button[data-time="{time}"]`. 모든 시간 모드에서는 모든 시간 버튼만 선택하는 표현식(예: `button[data-time]`)을 사용합니다. |
| 예약 진행 버튼 선택자 | 날짜와 시간을 선택한 뒤 첫 화면 하단 | 다음단계/예약하기 버튼 | 참고 페이지 HTML에서 확인한 값은 `button[data-click-code="nextbuttonview.request"]`입니다. 페이지마다 다를 수 있습니다. |
| 최종 확정 버튼 선택자 | 다음단계 이후 신청 정보·약관 등을 확인하는 화면 | 실제 예약/신청을 제출하는 버튼 | 그 화면까지 직접 이동한 뒤 해당 버튼을 검사해서 복사합니다. 상품마다 다르므로 공통값을 임의로 넣지 마세요. |

`{date}`는 현재 확인 중인 날짜(예: 2026-10-07), `{day}`는 일 숫자(예: 7), `{time}`은 입력한 시간(예: 09:00)으로 확장이 바꿉니다. 템플릿을 개발자도구에서 검사할 때는 실제 값으로 바꾸어 검색하세요.

여러 날짜를 감시하면서 특정 날짜의 `nth-child` 선택자를 그대로 넣으면 다른 날짜를 클릭할 수 있습니다. 그런 선택자는 사용하지 말고 기본값 또는 실제 날짜 속성의 템플릿을 사용하세요. 최종 확정 버튼은 검사만 하고 실제 클릭하지 않아도 선택자를 복사할 수 있습니다. 현재 확장은 별도 페이지로 이동한 뒤 자동 확정을 이어가는 기능이 없으므로 최종 화면이 새 페이지라면 직접 확정해야 합니다.
