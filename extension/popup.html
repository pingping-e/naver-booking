네이버 예약 감시

원하는 날짜 (1~5개, 입력 순서대로 확인)

날짜마다 순서대로 확인합니다. 첫 날짜부터 모두 확인한 뒤 다음 회차까지 기다립니다. 예약 가능한 시간을 찾으면 나머지 날짜 확인을 중단합니다.

하나 이상 추가하세요. 추가한 순서대로 우선 확인합니다.

예약 가능한 모든 시간을 확인합니다.

날짜·시간은 자동 저장되어 다음에 열 때 복원됩니다.

인원 선택이 필요한 예약만 입력하세요. 가게에서 허용하는 인원으로 선택합니다.

랜덤 새로고침 간격

가게별 필수 입력 미리 설정

날짜·시간을 직접 선택한 뒤, 나타나는 각 옵션 화면에서 값을 저장하고 다음 단계로 이동하세요. 마지막 화면까지 확인한 경로와 단계별 설정 상태를 표시합니다.

    날짜·시간 선택 뒤 나타나는 인원 구성·수량·옵션·추가정보는 자동으로 표시됩니다. 값을 입력하고 저장하세요.

    화면에서 읽어 온 항목별 인원을 입력하고 저장하세요. 구성 합계는 예약 인원과 같아야 합니다.

    저장된 중간 단계 관리
    최종 신청 추가정보

    필수 동의와 선택지가 하나인 확인 항목은 자동 선택합니다. 여러 선택지가 있는 항목은 실제 목록에서 미리 지정해 저장하세요. 저장한 값은 자동 예약 진행 시 적용됩니다.

    입력값은 이 브라우저에 저장되고 해당 예약 상품에만 적용됩니다. 비밀번호·결제정보는 입력하지 마세요.

    먼저 네이버에 로그인하세요. 기본 모드는 신청 화면에서 추가정보를 적용한 후 최종 제출 전에 멈춥니다. 결제 버튼은 자동 확정 설정과 관계없이 직접 눌러야 합니다. 브라우저가 열려 있어야 하며 로그인·인증은 직접 처리하세요.

    알림 소리

    선택한 소리는 자동 저장됩니다. 최종 신청 화면에 도착하면 알림과 함께 재생합니다.

      알림이 안 보이나요?

      시스템 알림 설정에서 Chrome 알림과 배너를 허용하고 집중 모드를 확인하세요. 업데이트한 확장과 예약 탭을 새로고침해야 새 기능이 적용됩니다.
