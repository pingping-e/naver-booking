매번 범위 안에서 새 시간을 뽑습니다. 로딩·절전 상태에서는 늦어질 수 있습니다.

신청 화면에서 설정한 값만 선택합니다. 선택할 수 없는 항목은 다른 값으로 대체하지 않고 중지합니다.

가게별 필수 입력 미리 설정

로그인한 예약 페이지에서 날짜·시간을 골라 최종 신청 화면까지 이동한 뒤, 아래 버튼을 누르세요. 필수 항목과 선택지를 읽어옵니다.

입력값은 이 브라우저에 저장되고 해당 예약 상품에만 적용됩니다. 비밀번호·결제정보는 입력하지 마세요.

고급 설정 (기본값으로 작동하지 않을 때만)

날짜·시간·다음단계 버튼은 자동 인식합니다. 참고 상품의 달력, 오전/오후 시간 구역과 다음단계 버튼을 확인해 반영했습니다. 기본 인식이 되면 비워두세요. 아래 도움말에서 선택자를 찾는 방법을 확인하세요.

날짜 선택자의 {date}는 YYYY-MM-DD, {day}는 일 숫자로 바뀝니다. 여러 날짜를 등록할 때 고정 날짜 선택자는 사용할 수 없습니다.

선택자를 어디서 찾나요? (설명 보기)

먼저 네이버에 로그인하세요. 기본 모드는 신청 화면에서 추가정보를 적용한 후 최종 제출 전에 멈춥니다. 브라우저가 열려 있어야 하며 로그인·인증·결제는 직접 처리해야 할 수 있습니다.
