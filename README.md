# 네이버 자동예약 매크로 확장 프로그램

<img src="extension/icons/icon-128.png" width="48" height="48" alt="자동예약 달력 아이콘">

원하는 날짜·시간의 빈자리를 주기적으로 확인하고, 미리 저장한 필수 정보를 입력해 예약 신청까지 진행하는 크롬 확장 프로그램입니다.

## 다운로드 및 설치

1. [최신 버전 다운로드](https://github.com/pingping-e/naver-booking/archive/refs/heads/main.zip)를 눌러 ZIP 파일을 받고 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions`를 입력하고, 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램 로드**를 누르고, 압축을 푼 폴더 안의 **extension** 폴더를 선택합니다.

## 사용 방법

1. 크롬에서 네이버에 로그인한 뒤 확장 프로그램 아이콘을 엽니다. 아이콘은 오른쪽 위 퍼즐 모양 버튼에서 찾을 수 있습니다.
2. **예약 페이지 주소**와 원하는 날짜·시간을 입력합니다. 인원 선택이 필요한 상품은 **예약 인원**도 입력합니다.
3. 처음 사용하는 상품은 **예약 설정 시작**을 누르고, 화면 안내에 따라 예약에 필요한 항목을 저장합니다.
4. 확인 간격, 최종 자동 신청 여부, 알림 소리를 선택하고 **감시 시작**을 누릅니다.

**예약 탭과 크롬은 열어 두세요.** 확장 창을 닫거나 다른 탭을 사용해도 동작합니다. 멈추려면 **감시 중지**를 누릅니다.

**최종 예약 신청도 자동 클릭**을 켜면 최종 신청까지 진행합니다. 끄면 최종 신청 화면에서 대기합니다. 결제는 직접 진행해야 합니다.
