# 네이버 예약 시간 감시

네이버 예약 상품 페이지의 원하는 날짜·시간을 주기적으로 확인하는 Chrome Manifest V3 확장프로그램 MVP입니다.

## 설치와 사용
클라우드의 `/workspace` 경로는 내 컴퓨터에서 바로 선택할 수 없습니다. 먼저 확장 파일을 다운로드하고 ZIP 압축을 풀어 주세요. ZIP 파일이나 저장소 최상위 폴더가 아니라 `manifest.json`이 바로 들어 있는 `extension` 폴더를 선택해야 합니다.

1. 주소창에 `chrome://extensions`를 입력한 뒤 Chrome 확장프로그램 관리에서 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**로 이 저장소의 `extension` 폴더를 선택합니다.
2. 네이버에 로그인한 뒤 확장 아이콘에서 예약 상품 주소, 날짜(최대 5개), 시간 조건(전체 시간 / 특정 시간 / 지정 시간 이후 / 시간 범위), 확인 간격(최소 15초)을 입력합니다.
3. 참고 상품은 날짜·시간·다음단계 버튼을 자동 인식하므로 선택자를 입력하지 않아도 됩니다. 특정 사이트 구조에서 기본 인식이 실패한 경우에만 고급 설정을 사용하세요.
4. 감시 시작을 누르면 전용 예약 탭이 열립니다. 활성 시간을 선택하고 다음단계로 이동한 뒤, 미리 저장한 필수 입력을 적용합니다. 기본 모드는 최종 제출 전에 멈춥니다. 내용 확인 후 직접 신청하세요.
5. 최종 신청까지 원하면 자동 확정을 켜세요. 제공된 네이버 신청 버튼은 기본 인식하며, 화면이 다를 때만 고급 선택자를 지정하세요. 예약이나 결제가 발생할 수 있습니다. 완료 여부는 예약 내역에서 확인하세요.
6. 중지 버튼 또는 전용 탭 닫기로 종료합니다. 브라우저 재시작 후에는 다시 시작해야 합니다.

참고 상품의 실제 달력·시간 DOM과 날짜·시간 선택, 다음단계 클릭을 Chromium에서 확인했습니다. 2026-10-19 마감 처리, 2026-10-26의 특정 시간(18:00)과 전체 시간 모드를 콘텐츠 스크립트로 검증했습니다. 로그인 이후 최종 제출 화면과 실제 예약 성공은 검증하지 않았습니다. 동일 상품의 `/request` 신청 페이지로 이동하면 작업을 이어갑니다. 로그인이나 추가 인증이 필요한 경우 직접 처리해야 합니다. 다른 경로나 지원되지 않는 필수 입력은 자동 처리하지 않습니다. 캡차·로그인·결제 입력을 우회하지 않습니다. 자동화 사용은 사이트 정책을 확인하세요.

## 개발 및 검증
Node.js 24에서 외부 의존성 없이 `npm test`와 `npm run check`를 실행합니다. 확장 수정 후 Chrome에서 확장을 새로고침하고 예약 탭도 다시 불러오세요.

설계와 수동 검증 항목: [docs/design.md](docs/design.md).

## 0.1.1 변경 사항
- 최소 확인 간격 15초. 30초 미만은 예약 탭의 타이머를 사용합니다. 현재 확인이 끝나야 다음 새로고침을 수행하므로 로딩이 오래 걸리거나 절전·백그라운드 제한이 있으면 간격이 늘어납니다.
- 시간 입력을 비우면 해당 날짜의 활성 시간 버튼 중 화면에서 처음 발견한 시간을 선택합니다.
- 전체 시간 모드에서 시간 선택자는 모든 시간 버튼을 선택하는 CSS를 입력하세요. `{time}` 템플릿은 특정 시간을 입력한 경우에 사용하며, 전체 시간 모드에서는 기본 시간 인식으로 전환됩니다.
- 화면 선택자는 날짜·시간·예약 버튼을 식별하는 CSS 표현식입니다. 기본 인식이 작동하면 비워 두세요.

## 0.1.2 변경 사항
- 날짜를 1~5개 등록하면 입력 순서대로 확인합니다. 시간 목록은 모든 날짜에 공통 적용됩니다.
- 확인 간격은 날짜 한 개를 확인하고 다음 날짜로 넘어가는 간격입니다. 5개 날짜를 15초 간격으로 감시하면 같은 날짜는 대략 75초마다 확인됩니다. 로딩·절전으로 지연될 수 있습니다.
- 날짜별 화면 상태와 오래된 메시지를 구분해 이전 날짜의 검사 결과가 다른 날짜의 예약을 진행하지 않도록 합니다.
- [선택자 찾는 방법](docs/selectors.md)을 추가했습니다. 확장 설정에도 도움말 링크가 있습니다.

## 0.1.3 변경 사항
- 실제 참고 상품 화면을 조사하고 날짜·시간·다음단계 기본 인식을 등록했습니다. 선택자는 고급 설정으로 이동했습니다.
- `오후`/`PM` 구역의 `6:00`을 `18:00`으로 정규화해 원하는 시간과 정확하게 비교합니다.
- 마감 날짜에서는 예약을 진행하지 않고 마감 로그를 남긴 뒤 다음 확인을 기다립니다.
- [실제 페이지 조사 및 검증 기록](docs/site-investigation.md).

## 0.1.4 변경 사항
- 가게별 필수 입력을 최종 신청 페이지에서 읽어와 설정하고 브라우저 로컬에 저장합니다. 체크박스·라디오·일반 드롭다운·필수 텍스트 입력을 지원합니다.
- 사용 방법: 최종 신청 탭에서 확장 열기 → **현재 탭의 필수 항목 불러오기** → 값을 지정 → **필수 입력 설정 저장** → 날짜·시간 설정 후 감시 시작.
- 필수 항목은 상품 URL별로 분리합니다. 다른 상품의 값이나 임의 선택으로 대체하지 않습니다.
- 현재 참고 상품 기본값은 **시술 선택: 필러 / 내원 경로: 유튜브**입니다. 일반 필수 입력 프로필을 저장하면 그 프로필이 우선합니다.
- 사용자가 제공한 최종 버튼 `button[data-click-code="submitbutton.submit"]`을 등록했습니다.
- `/request` 페이지로 이동한 뒤에도 이어서 입력합니다. 자동 확정을 끄면 입력 후 중지하고, 켜면 신청 버튼을 1회 클릭합니다. 예약 성공이나 업체 최종 확정과는 구분하세요.
- [필수 입력 설정 설명](docs/required-fields.md).

## 0.1.5 변경 사항
- 날짜 입력은 기본 1개만 표시하며 **+ 날짜 추가**로 최대 5개까지 늘립니다. 추가한 날짜는 삭제할 수 있고 저장한 날짜 목록은 팝업을 다시 열면 복원됩니다.
- 시간 조건은 전체 시간, 특정 시간 선택, 지정 시간 이후, 시간 범위 중에서 고릅니다. 특정 시간은 시간 선택기로 하나 이상 추가하고 추가 순서대로 우선 확인합니다.
- `12:00 이후`는 12:00부터, `14:00~15:00`은 양 끝을 포함합니다. 시간 범위는 같은 날짜 안에서 지정하며 다음 날로 넘어가는 범위는 지원하지 않습니다.
