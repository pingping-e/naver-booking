# 네이버 예약 시간 감시

<img src="extension/icons/icon-128.png" width="48" height="48" alt="예약 시간 감시 아이콘">

원하는 날짜와 시간에 빈자리가 생기는지 자동으로 확인해 주는 크롬 확장프로그램입니다. 예약 가능한 시간을 찾으면 예약을 진행하고, 미리 저장한 필수 정보를 입력합니다.

네이버 공식 프로그램이 아닙니다. 가게마다 예약 화면이 달라 일부 기능이 작동하지 않을 수 있습니다.

[참고 예약 페이지 열기](https://booking.naver.com/booking/6/bizes/193536/items/2915045)

## 다운로드와 설치

1. [최신 버전 다운로드](https://github.com/pingping-e/naver-booking/archive/refs/heads/main.zip)를 눌러 ZIP 파일을 받습니다.
2. ZIP 파일의 압축을 풉니다.
3. 크롬 주소창에 `chrome://extensions`를 입력합니다.
4. 오른쪽 위의 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램 로드**를 누르고, 압축을 푼 폴더 안의 **extension** 폴더를 선택합니다.
6. 크롬 오른쪽 위의 퍼즐 모양 버튼에서 **네이버 예약 시간 감시**를 고정하면 편리합니다.

“매니페스트 파일이 없습니다”라는 오류가 나오면 선택한 폴더를 확인해 주세요. ZIP 파일이나 바깥쪽 폴더가 아니라 **extension 폴더**를 선택해야 합니다.

## 예약 확인 시작하기

1. 크롬에서 네이버에 로그인합니다.
2. 확장 아이콘을 눌러 **예약 상품 주소**를 입력합니다. 가게 소개 주소가 아니라 날짜와 시간을 고르는 예약 페이지 주소를 넣어 주세요.
3. 원하는 날짜를 선택합니다. **+ 날짜 추가**로 최대 5개까지 등록할 수 있습니다. 첫 날짜부터 순서대로 확인하므로 가장 원하는 날짜를 먼저 넣어 주세요.
4. 원하는 시간 조건을 고릅니다.
5. 확인 간격을 정하고 **감시 시작**을 누릅니다.

예약 탭이 열리면 같은 페이지에서 등록한 날짜를 순서대로 확인합니다. 원하는 시간을 찾으면 예약을 진행하고 나머지 날짜 확인을 멈춥니다. 찾지 못하면 정해 둔 간격만큼 기다렸다가 새로고침해 다시 확인합니다.

**중지**를 누르거나 예약 탭을 닫으면 종료됩니다.

## 시간 조건 고르기

| 조건 | 사용 예시 |
| --- | --- |
| 전체 시간 | 아무 시간이나 괜찮을 때 |
| 특정 시간 | 14:00, 15:30처럼 원하는 시간을 하나 이상 선택 |
| 지정 시간 이후 | 12:00부터 가능한 시간 확인 |
| 시간 범위 | 14:00부터 15:00까지 확인 |

같은 시간 조건을 모든 날짜에 적용합니다. 시간 범위의 시작과 끝도 포함합니다. 특정 시간을 여러 개 등록하면 먼저 추가한 시간을 우선 확인합니다.

## 확인 간격 정하기

**최소 시간**과 **추가 범위**를 초 단위로 입력합니다. 아래 안내 문구에서 실제 간격을 확인할 수 있습니다.

| 최소 시간 | 추가 범위 | 확인 간격 |
| --- | --- | --- |
| 5초 | 0초 | 매번 5초 |
| 5초 | 15초 | 매번 5~20초 중 무작위 |
| 15초 | 45초 | 매번 15~60초 중 무작위 · 기본값 |

최소 시간은 5~120초, 추가 범위는 0~120초로 입력합니다. 최소 시간이 5초 미만이면 오류가 표시되고 시작할 수 없습니다.

간격은 등록한 날짜를 모두 확인한 뒤부터 계산합니다. 페이지 로딩이나 컴퓨터 절전 상태 때문에 실제 확인이 더 늦어질 수 있습니다.

## 예약에 필요한 정보를 미리 저장하기

시술 종류, 방문 경로, 요청사항처럼 예약 신청에 필요한 정보를 미리 저장할 수 있습니다.

1. 예약 사이트에서 날짜와 시간을 골라 **최종 예약 신청 화면**까지 이동합니다.
2. 확장을 열고 **현재 탭의 필수 항목 불러오기**를 누릅니다.
3. 필요한 값을 입력하고 **필수 입력 설정 저장**을 누릅니다.
4. 날짜와 시간 조건을 설정하고 감시를 시작합니다.

설정은 예약 상품별로 저장됩니다. 기존 시술 예약 상품은 따로 저장한 값이 없으면 **제모 / 네이버 검색**을 사용합니다. 아래 참고 예약 페이지를 포함한 다른 상품은 필수 정보를 직접 불러와 저장해 주세요. 직접 저장한 설정이 있으면 저장한 값이 우선합니다.

## 최종 예약 신청

기본 설정에서는 필수 정보를 입력한 뒤 멈춥니다. 예약 내용을 확인하고 직접 신청 버튼을 눌러 주세요.

**자동 확정**을 켜면 최종 예약 신청 버튼까지 한 번 누릅니다. 실제 예약 신청이 발생할 수 있으므로 날짜·시간·필수 정보를 먼저 확인해 주세요. 버튼을 눌렀다는 것만으로 예약 성공을 보장하지는 않으니 **네이버 예약 내역**에서 결과를 확인하세요.

## 로그 확인과 문제 해결

최근 기록 10개가 표시됩니다.

- **예약 가능: 18:00**: 해당 날짜에 원하는 조건에 맞는 시간을 찾았습니다.
- **예약 불가**: 해당 날짜가 마감됐거나 원하는 조건에 맞는 시간을 찾지 못했습니다.
- **확인 실패 / 안전 중지**: 화면을 읽지 못했거나 입력에 문제가 있습니다. 예약 불가로 확인한 것은 아닙니다. 예약 화면과 로그인 상태를 확인한 뒤 다시 시작해 주세요.

화면이 로딩 중일 때는 날짜 버튼이 준비될 때까지 최대 15초 기다립니다. 로그인이나 추가 인증이 필요하면 직접 처리해야 합니다. 브라우저를 완전히 종료했다가 다시 켜면 감시도 다시 시작해 주세요.

**고급 설정**은 기본 인식이 작동하지 않는 경우에만 사용합니다. 보통은 비워 두면 됩니다.

## 새 버전으로 바꾸기

감시를 중지한 뒤 최신 ZIP을 받아 압축을 풉니다. 기존에 로드한 `extension` 폴더의 파일을 새 파일로 교체하고, `chrome://extensions`에서 확장의 새로고침 버튼을 누릅니다. 열려 있던 예약 탭도 새로고침한 뒤 다시 시작해 주세요.
