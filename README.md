# 네이버 예약 시간 감시

<img src="extension/icons/icon-128.png" width="48" height="48" alt="예약 시간 감시 아이콘">

원하는 날짜·시간에 빈자리가 생기면 예약을 진행하는 크롬 확장 프로그램입니다. 예약에 필요한 정보를 미리 저장하면 자동으로 입력하고, 설정에 따라 최종 신청 버튼까지 누릅니다.

[최신 버전 다운로드](https://github.com/pingping-e/naver-booking/archive/refs/heads/main.zip) · [예약 페이지 예시](https://booking.naver.com/booking/6/bizes/193536/items/2915045)

## 사용하기

1. 크롬에서 네이버에 로그인합니다.
2. 크롬 오른쪽 위의 확장 프로그램 아이콘을 눌러 **네이버 예약 시간 감시**를 엽니다. 아이콘이 안 보이면 퍼즐 모양 버튼에서 찾을 수 있습니다.
3. **예약 페이지 주소**를 입력하고 원하는 날짜·시간을 등록합니다. 인원 선택이 필요한 상품은 **예약 인원**도 입력합니다.
4. 처음 사용하는 상품은 아래의 **예약 설정 시작**으로 필수 항목을 저장합니다.
5. 확인 간격, 최종 자동 신청 여부, 알림 소리를 선택하고 **감시 시작**을 누릅니다.

등록한 날짜를 첫 번째부터 순서대로 확인합니다. 원하는 시간을 찾으면 예약을 진행하고, 없으면 설정한 간격 뒤에 다시 확인합니다.

확장 창을 닫거나 다른 탭을 사용해도 계속 동작합니다. **예약 탭과 크롬은 열어 두세요.** **감시 중지**를 누르거나 예약 탭을 닫으면 멈춥니다. 크롬을 종료했다 다시 열었을 때는 감시를 다시 시작해야 합니다.

## 예약에 필요한 정보 저장하기

가게에 따라 인원 구성, 상품 수량, 필수 옵션, 추가정보가 다릅니다. 처음 한 번 해당 상품의 예약 과정을 따라가며 저장합니다.

1. 확장에서 **예약 설정 시작**을 누릅니다. 새 예약 탭이 열리고 진행 중이던 감시는 중지됩니다.
2. 사이트에서 날짜·시간과 필요한 인원을 선택합니다. 이때 고르는 조건은 설정을 위한 것이며, 확장에 등록한 희망 날짜·시간을 바꾸지 않습니다.
3. 필요한 항목이 확장에 자동으로 표시됩니다. 값을 입력하고 **저장하고 다음**을 누릅니다.
4. 최종 신청 화면에서는 필요한 값을 입력하고 **설정 저장**을 누릅니다. 설정 중에는 사이트의 신청·결제 버튼을 누르지 않습니다.
5. **마지막 화면까지 확인됨**과 단계별 준비 상태를 확인한 뒤 **감시 시작**을 누릅니다.

필수 동의나 선택지가 하나뿐인 확인 항목은 자동 처리합니다. 여러 선택지나 직접 입력할 값이 있는 항목만 지정하면 됩니다. 최종 화면에 별도 입력이 없으면 빈 설정을 저장할 필요가 없습니다.

저장한 항목은 해당 예약 상품에만 적용됩니다. 설정한 뒤에는 다음 감시에서도 그대로 사용합니다. 사이트의 항목이 바뀌면 **예약 설정 시작**으로 다시 확인하세요. 화면을 읽지 못하면 **다시 읽기** 버튼이 표시됩니다.

**예약 인원**은 사이트에 총인원을 고르는 항목이 있을 때 사용합니다. 성인·어린이 등의 인원 구성은 합계가 총인원과 같아야 합니다. 텐트 수량이나 이용료 수량은 방문 인원과 별개이므로 해당 항목에 맞게 입력하세요.

## 날짜·시간과 확인 간격

날짜는 **+ 날짜 추가**로 최대 5개까지 등록합니다. 가장 원하는 날짜를 먼저 넣으세요. 날짜·시간 조건은 자동 저장되어 다음에 열 때 복원됩니다.

오늘부터 선택할 수 있으며, 한국 시간 기준으로 지난 날짜는 등록할 수 없습니다. 감시 중 날짜가 지나면 남은 날짜만 확인하고, 모두 지나면 종료합니다.

| 시간 조건 | 확인할 시간 |
| --- | --- |
| 전체 시간 | 예약 가능한 모든 시간 |
| 특정 시간 선택 | 추가한 시간 중에서 입력 순서대로 |
| 지정 시간 이후 | 지정한 시간을 포함해 그 이후 |
| 시간 범위 | 시작·종료 시간을 포함한 범위 |

같은 시간 조건을 모든 날짜에 적용합니다.

확인 간격은 **최소 시간 + 추가 범위**로 정합니다. 기본값은 **15~60초**입니다.

| 최소 시간 | 추가 범위 | 실제 확인 간격 |
| --- | --- | --- |
| 5초 | 0초 | 매번 5초 |
| 5초 | 15초 | 5~20초 중 무작위 |
| 15초 | 45초 | 15~60초 중 무작위 |

최소 시간은 5~120초, 추가 범위는 0~120초입니다. 등록한 날짜를 모두 확인한 뒤 기다리는 시간이며, 로딩이나 절전 상태에 따라 늦어질 수 있습니다.

감시 중에 조건을 수정했다면 **감시 시작**을 다시 눌러 새 조건으로 실행하세요.

## 최종 신청과 알림

**최종 예약 신청도 자동 클릭**을 켜면 결제가 없는 최종 신청 버튼을 한 번 누릅니다. 끄면 필수 정보를 입력한 최종 화면에서 대기하므로 직접 신청하면 됩니다. **결제 버튼은 항상 직접 눌러야 합니다.** 실제 접수 여부는 네이버 예약 내역에서 확인하세요.

최종 신청 화면에 도착하면 자동 클릭 설정과 관계없이 **화면 알림과 소리로 한 번 알려줍니다.** 다른 탭이나 프로그램을 보고 있어도 알림을 받을 수 있습니다. 이 알림은 최종 화면 도착을 뜻하며, 예약 완료 알림은 아닙니다. 예약 불가나 실패에는 알림을 띄우지 않습니다.

**알림 소리**에서 원하는 소리를 선택하세요. 선택하면 자동 저장됩니다.

| 소리 | 설명 |
| --- | --- |
| 내 알림음 · alert.mp3 | 기본 알림음 |
| 차임 | 세 음이 차례로 울리는 소리 |
| 맑은 종 | 맑게 울렸다가 서서히 잦아드는 소리 |
| 짧은 전자음 | 짧게 두 번 울리는 소리 |
| 소리 없음 | 화면 알림만 표시 |

**미리 듣기**로 확인할 수 있습니다. 소리는 확장 자체에서 재생하므로 확장 창을 닫아도 동작합니다.

## 문제가 있을 때

확장 맨 아래에 최근 로그 10개가 표시됩니다.

- **예약 가능**: 원하는 조건에 맞는 시간을 찾아 예약을 진행합니다.
- **예약 불가**: 해당 날짜에 조건에 맞는 예약 가능한 시간이 없습니다.
- **안전 중지 / 확인 실패**: 화면이나 입력을 확인하지 못했습니다. 로그인과 예약 화면을 확인하고 다시 시작하세요.

예약 진행 전 화면 로딩이 늦어 확인하지 못하면 약 5초 뒤에 최대 2회 다시 확인합니다. 정상적으로 날짜를 모두 확인하면 재시도 횟수가 초기화됩니다. 로그인·인증, 화면 구조나 예약 조건의 불일치, 예약 진행을 시작한 뒤의 오류는 자동 재시도하지 않습니다.

알림이 안 보이면 **알림이 안 보이나요? → 알림 테스트**를 눌러 확인하세요. macOS에서는 **시스템 설정 → 알림 → Google Chrome**에서 알림과 배너를 허용하고 집중 모드를 확인합니다. 알림 크기와 표시 시간은 OS 설정을 따릅니다.

로그인이나 추가 인증은 직접 처리해야 합니다. 네이버 공식 프로그램이 아니며, 가게의 화면 변경에 따라 다시 설정하거나 프로그램을 수정해야 할 수 있습니다.

## 설치와 업데이트

<details>
<summary>처음 설치하는 경우</summary>

1. 위의 **최신 버전 다운로드**로 ZIP 파일을 받아 압축을 풉니다.
2. 크롬의 확장 프로그램 관리 화면에서 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램 로드**를 눌러 압축을 푼 폴더 안의 **extension** 폴더를 선택합니다.

개발자 모드를 켜야 로드 버튼이 표시됩니다. 설치 후에는 확장 아이콘을 눌러 사용하면 됩니다.

“매니페스트 파일이 없습니다”라는 오류가 나오면 바깥 폴더가 아닌 **extension 폴더**를 선택했는지 확인하세요.

</details>

<details>
<summary>새 버전으로 업데이트하는 경우</summary>

1. 감시를 중지하고 최신 ZIP을 받아 압축을 풉니다.
2. 기존에 크롬에 로드한 **extension 폴더의 파일**을 새 파일로 교체합니다.
3. 크롬의 확장 프로그램 관리 화면에서 이 확장의 **새로고침**을 누릅니다.
4. 열려 있던 예약 탭도 새로고침하고 감시를 다시 시작합니다.

확장 맨 아래 **알림이 안 보이나요?**를 펼치면 적용된 버전을 확인할 수 있습니다.

</details>
