# 가게별 필수 입력을 미리 설정하기

1. 새 버전의 확장을 로드하고 네이버 예약 탭을 다시 불러옵니다. 그래야 필수 항목을 읽는 콘텐츠 스크립트가 페이지에 적용됩니다.
2. 네이버에 로그인하고 사용할 상품에서 날짜·시간을 선택하여 최종 예약 신청 페이지로 이동합니다. 이 과정에서는 실제 신청 버튼을 누르지 않아도 됩니다.
3. 해당 탭을 보고 있는 상태에서 확장 아이콘을 누르고 **현재 탭의 필수 항목 불러오기**를 선택합니다.
4. 필수 항목마다 값을 지정합니다. 체크박스 목록은 여러 개 선택할 수 있으며, 일반 선택 목록은 하나만 선택합니다. 필수 텍스트 입력에는 실제 사용할 값을 넣습니다.
5. **필수 입력 설정 저장**을 누릅니다. 적용할 상품 주소와 프로필이 저장됩니다. 값은 브라우저 로컬 저장소에 보관되고 별도 서버로 보내지지 않습니다.
6. 날짜 1~5개와 시간·간격을 설정하고 감시를 시작합니다. 신청까지 자동 진행하려면 **최종 확정도 자동 클릭**을 켭니다. 끄면 필수 입력을 적용한 뒤 최종 제출 전에 멈춥니다.

여러 가게는 각각 최종 신청 페이지에서 한 번씩 설정하세요. 상품 URL을 바꾸면 해당 상품에 저장한 프로필을 불러옵니다. 실행 중 설정을 바꿨다면 중지 후 다시 시작해야 반영됩니다. 필수 항목이 추가되거나 옵션이 달라지면 다시 불러와 저장하세요.

원래 참고 상품은 별도 일반 프로필을 저장하지 않아도 시술 `제모`, 내원 경로 `네이버 검색` 기본값을 적용합니다. 일반 프로필을 저장하면 그 값이 우선합니다. 지정값이 없거나 선택 불가이면 다른 값을 고르지 않습니다.

지원 범위는 최종 `/request` 페이지의 네이버 필수 그룹과 일반 HTML required/aria-required 필드입니다. 별도 커스텀 위젯, 파일 업로드, 비밀번호, 복수 선택 select, 이름이 중복되어 구분할 수 없는 입력은 자동 처리하지 않습니다. 이런 경우 화면에서 직접 입력하세요. 결제정보나 비밀번호는 프로필에 저장하지 마세요.

## 검증 기록
자동 테스트는 프로필의 상품 범위, 텍스트 이벤트, 선택 값 유지/변경, 누락 값 중지, 최종 제출 잠금을 확인합니다. Chromium 로컬 재현 화면에서는 사용자 제공 HTML을 사용해 필러/유튜브 선택 및 수동/자동 모드, 선택지 누락 중지를 검증했습니다. 다른 가게를 가정한 라디오·요청사항 입력, 팝업 항목 불러오기·저장·시작, 날짜/시간 화면에서 신청 문서로 이동 후 작업을 이어가는 경로도 검증했습니다. 실제 예약 서버에 제출하지 않았으며 로그인한 실제 페이지의 전체 통합 검증은 남아 있습니다.
